♿ Accessible Web — Inclusive Accessibility Project

This project is a modern and accessible webpage designed to demonstrate essential accessibility practices. It includes multiple tools that support users with visual, auditory, cognitive, and motor disabilities.

🌟 Accessibility Features
🔊 Text-to-Speech (Screen Reader Simulation)

Reads the page content aloud using the browser’s Speech Synthesis API.

🔠 Font Size Controls

Increase text size (A+)

Decrease text size (A−)

⚫ High-Contrast Mode

Improves visibility for users with low vision.

🌙 Manual Dark Mode

Optional dark theme for visual comfort.

⤵️ Skip-to-Content Link

Helps keyboard-only and screen reader users reach the main section quickly.

🖼️ Accessible Images

All images include descriptive alt text.

🦻 VLibras – Brazilian Sign Language Support

Integrated VLibras Widget, which translates page content into Libras, making the site accessible for Brazilian Deaf users who rely on sign language.

Note: Although this is an English-language project, the VLibras tool is included to demonstrate international accessibility practices.

🤝 Semantic and Clean HTML Structure

Improves navigation for assistive technologies.

🧩 Technologies Used

HTML

CSS

JavaScript

🎯 Purpose

This project was created to show how simple accessibility features can transform a page into a more inclusive and user-friendly environment for people with disabilities.

Accessibility is not optional — it is essential.
